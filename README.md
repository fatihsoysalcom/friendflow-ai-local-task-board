# FriendFlow AI Local Task Board

This Python script demonstrates a simple local, private task management board inspired by FriendFlow AI. It allows adding, viewing, updating status, and removing tasks, saving them to a JSON file for persistence without external services.

## Language

`python`

## How to Run

Save the code as `friendflow_ai_demo.py` and run it from your terminal using `python friendflow_ai_demo.py`.
